# Lessons learned — do not repeat (ussdgw-jainslee)

Short memory for Digicom footguns. Prefer this + OTA peer [`lessons.md`](../../../../ota-service/ota-sim-push/docs/agents/lessons.md) over rediscovering the same mistakes.
